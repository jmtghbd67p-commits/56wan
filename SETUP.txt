아이랑 어디갈까? - 네이버 검색 + 카카오 길찾기·지도 버전

필수 Vercel 환경변수
1) KAKAO_REST_KEY
   - Kakao Developers 앱의 REST API 키
   - Kakao Mobility 차량 길찾기·소요시간 측정에만 사용

2) NAVER_API_KEY_ID
3) NAVER_API_KEY_SECRET
   - NAVER Cloud Platform > NAVER API HUB에서 발급
   - 이미지/블로그/카페글/웹/지역 검색에 사용

Vercel 설정
Project > Settings > Environment Variables 에 위 3개를 Production에 추가한 뒤 Redeploy.

데이터 역할
- 네이버 지역·블로그 검색: 장소 후보 수집과 아이 동반·체험 근거 확인
- 카카오 Mobility: 네이버에서 찾은 장소까지의 실제 차량 소요시간 측정
- 카카오 지도 JavaScript SDK: 출발지 지도 선택 화면의 한글 지도 표시

주의
- REST API 키와 네이버 API 키는 Vercel Environment Variables에만 저장합니다.
- 카카오 JavaScript 키는 웹 지도 SDK가 브라우저에서 사용하는 공개 키이므로 index.html에 포함될 수 있습니다. 카카오 개발자 콘솔의 Web 플랫폼에 서비스 도메인을 등록해야 합니다.
